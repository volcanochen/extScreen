## ExtScreen 副屏助手 v1.2.0

把 Android 手机变成 Windows 桌面的**一块扩展屏**，并且内置一套全新的
**窗口投屏**：把任意单个窗口投到手机上，手机上可直接触摸操作该窗口。

> 本版是「窗口投屏」功能的第一个正式发布：多路并发、多手机、USB 离线直投、
> 触摸回传、标题栏按钮、商品名对照表全部就位。

### 下载

| 文件 | 说明 |
|---|---|
| `ExtScreen-Dock-v1.2.0.exe` | 托盘主程序（**双击运行，需要管理员权限**） |
| `ExtScreenViewer-v1.2.0.apk` | Android 副屏接收器（20KB，装一次即可；USB 手机未装时 Dock 会自动安装） |
| `sunshine-installer.msi` | Sunshine 串流主机端（**仅扩展屏模式**需要） |
| `MttVDD-25.7.23-signed-drivers-x86.zip` | 虚拟显示器驱动（**仅扩展屏模式**需要） |

### 两种用法

**A. 窗口投屏（本版新增，无需装驱动/Sunshine）**

1. 双击 `ExtScreen-Dock-v1.2.0.exe`
2. 手机装 `ExtScreenViewer-v1.2.0.apk`（或插 USB 让 Dock 自动装）
3. 托盘 → 窗口投屏 → 选择窗口并开始分享… → 一个界面里同时选窗口和手机
4. 手机自动亮屏出画面；停止投屏后手机自动恢复原状

**B. 传统扩展屏**

1. 装 `sunshine-installer.msi` → 装 `MttVDD` 驱动（托盘菜单里有一键修复）
2. 手机装 Moonlight 竖屏补丁版（见仓库 `docs/MOONLIGHT-PATCH.md`）
3. 托盘 → 开启扩展屏，即可把窗口拖到手机这块副屏上

### 窗口投屏功能一览

- **多路并发**：窗口 A→手机 1、窗口 B→手机 2 同时进行（独立端口 8123/8124…、独立 mDNS、独立手机记忆）
- **一路流多观众**：同一窗口再投另一台手机时不会踢掉已连的手机
- **合一的「窗口 + 手机」选择框**：窗口显示所属应用，手机显示商品名/系统版本/分辨率/尺寸
- **USB 离线直投**：`adb reverse` 回环，手机不开 WiFi、不插卡也能出画面；拔线自动退回 WiFi/mDNS
- **自动装 APK**：未安装接收器的手机投屏时自动 `adb install`
- **手机信息表**：内置 11,456 条「型号 → 商品名」对照表（Google Play 官方设备注册表），运行时零联网
- **触摸回传**：单指=左键、双指=右键、按住拖动=拖拽；只对被投窗口发消息，不动真实光标、不抢前台
- **窗口比例自适应**：按手机屏幕比例只调长或宽（保面积）；手机旋转跟随
- **三种快捷入口**：托盘菜单、窗口标题栏「投/停」小按钮、标题栏右键/Alt+Space 菜单
- **粘滞会话**：多会话下手机不会被 mDNS 抢到别的窗口；停止时只恢复本路拉起过的手机
- **清晰度可调**：默认 1080px 宽 / JPEG 80；`config.json` 里 `castWidth` / `castQuality` 可再调高
- **锁屏可投**：PC 经 adb 唤醒并解锁手机，接收器在锁屏上层直接显示画面

### 修复与稳定性

- 修复多会话「抢台」、窗口尺寸被交叉上报搞乱的问题
- 修复标题栏按钮导致全系统输入冻结（跨进程 Owner 输入队列耦合）——改为单实例前台跟随
- 低级钩子线程全面防阻塞（超时消息、剪贴板出线程、输入队列强制释放）
- 修复「窗口选择列表漏掉最大化窗口」（`showCmd=3` 被误判为最小化）
- 修复手机横屏右侧黑条（Chrome 74 不认识 `inset:`）
- 修复部署残留命令导致的「启动即死」

### 已知限制

- MJPEG 延迟约 0.1 秒，适合文档/终端/监控，不适合高速游戏
- .NET WinForms 窗口不读鼠标拖动标志，触摸拖拽无效（点击正常）
- 同一台手机同时只显示一路投屏
- 扩展屏模式左右各 9px 细黑边未消除
